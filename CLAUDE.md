# Frontend collaboration

Read AGENTS.md, docs/API-HANDOFF.md, docs/CLAUDE-DESIGN-BRIEF.md and BUILD-STATE.md. You own only apps/web/ and docs/frontend/.

Use the same local project folder as Codex. Do not create another repository, run create-next-app, replace the root package.json, switch branches or touch backend/provider credentials. Use React + Vite. Request dependencies in docs/frontend/REQUESTS.md rather than racing package-lock edits.

Design skills are instructions, not application dependencies. Read and apply the relevant ones. User requests for SVG-only visuals, deep black, tasteful glass, mobile usability and reduced motion take precedence over conflicting skill defaults. No Higgsfield or AI-generated images. Do not generate fake results or simulated success for the connected application.
